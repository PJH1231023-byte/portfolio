# 浮光守卫 · 第二版节奏与经济重构

## 本次要解决的问题

第一关操作变化少、敌人少且等待感强；金币来源单一；星尘和抽奖资源缺少直白解释；抽奖只给出文字概率、看不到完整奖品；关卡和角色的双重解锁使体验受限。

## 新规则

十关全部开放，每关记录最高一至三星。满血三星，剩余七至九点二星，一至六点一星。每关首通与首次三星分别奖励一张抽奖券。

十二秒准备后自动出怪，按时间连续推进，不等待上一波清空。第一关预定三十九只怪物，共六波；后续提升数量、敌群组合与入口压力，最后一关预定一百八十一只，包括一只首领。分裂 / 召唤物另计，必须清理后才判定胜利。

每关免费提供金币工坊，不占队伍，不进入奖池。每六秒生产十二 / 十八 / 二十六金币，升级分别花费九十 / 一百五十。金币还来自击败、波次补给和清除墨晶。生产与战斗统一受暂停、倍速影响。

每只怪物另奖励二至五星尘，失败仍保留。每关首通奖励二百起、每关递增二十五；重复通关八十起、每关递增八。星尘用于永久培养、道具与抽奖。

萤巡免费，其他十一位进入常驻抽奖池。前两抽固定给露米与烬团，确保减速和范围攻击的基础组合，不以纯随机决定新手是否有功能完整的队伍。新手与本次规则迁移赠送五张抽奖券，旧有伙伴与培养全部保留。

完整角色概率合计百分之三十六；四星碎片百分之二十四；当前心愿五星碎片百分之十八；道具百分之十七；星尘百分之五。所有奖品以图片、名称、单件概率展示，可点击了解功能。每五抽额外六枚心愿碎片，固定新手抽奖也计入。

## 设计取舍

初始低星负责低费用覆盖，减速与范围角色提供主动搭配，高星保留强度与较高部署成本。金币工坊的升级是回报较慢的投资，初期需要先建立火力，而非一开局只升级生产。

全部开放提供自由选择，但地图卡片与战前界面明确建议强度，不把高难地图伪装成可用零培养队伍轻松通关。通关与三星是两个不同目标。

旧版进行中的敌人队列不迁移，以免两种节奏混用；旧版永久进度不清空。原 v1 记录是历史方案，本文件与游戏 README 描述当前 v2 规则。

# 小游戏开发计划

记录日期：2026-09-07

## 当前优先：绒绒野餐会

用户参考底部瞄准发射、三个相同物件接触合成下一等级的小游戏，要求独立设计角色、美术、背景与界面，不使用花盆主题。

已确认采用新生成的动物和食物毛绒伙伴，原版星灵退出可玩主题。整套 UI 改为阳光野餐小院、奶油色桌布与鼠尾草绿控件。

### 已确认的产品结构

- 动物和食物自由选择，每个主题各自闯关，不把食物主题锁在动物通关之后。
- 每个主题是一局连续的八关旅程，过关保留桌面和发射队列，不再重新铺放一套高等级伙伴。
- 低级伙伴持续随机出现，不随关卡提高而被排除，也不按桌面对子自动补齐。第三级解锁后的随机权重固定为 60%、30%、10%，更高等级只能合成。
- 不设强制发射次数上限；桌面挤到警戒线且未完成目标才失败。失败可用剩余撤回挽救，否则从第一关重开，而非只重玩当前关。
- 每局三次撤回，不随过关补满。历史最高星光和各关最佳星星保留，星级按本关所用发射次数计算。
- 两套旅程分别保存关卡、星星与当前局面，切换后可以继续。
- 玩家头像与游戏主题分开选择；新动物和旧版经典角色均可作为头像。
- 原版角色不再作为发射物，不再提供第三套旧版主题。
- 角色以独立形象发射和碰撞，没有包围圆圈、白色底板或卡片背景。
- 合成距离与碰撞距离分开，提供随角色体积变化的额外容差，允许靠近但未紧贴的三个同级伙伴合成。

### 美术方向

保持用户已认可的两组角色，统一为可爱、短绒、温暖、物种轮廓清晰的设计。动物包括猫、狗、兔子、猪、牛、羊、老虎和小象；食物包括草莓、饭团、面包、布丁、桃子、西兰花、可颂和蛋糕。可以参考毛绒玩具的简洁亲和感与童话游戏的柔和比例，但不复制已有形象。素材生成记录位于 `games/starling-merge/ART-DIRECTION.md`。

### 待进一步体验的内容

本轮界面与闯关实现完成后，继续根据实际游玩反馈调整关卡难度、角色大小和操作手感。未完成浏览器检查的内容不视为已经验证。

## 下一项：萌宠塔防

方向已转为《保卫萝卜》类型的路线塔防，暂名「浮光守卫」。保留此前 `pet-garden-battle.html` 原型；目前完成玩法与美术提案，尚未替换为新的可玩版本。详细草案见 `docs/dream-guardians-design.md`。

- 怪物沿横向蜿蜒河道进攻，守卫部署在两岸，保护带生命值的终点花朵。关卡由简单 L 形过渡到折返和多入口。
- 角色采用大头小身体、服装配饰鲜明的原创动物守卫，区分水、火、光束、范围攻击与增益等功能。
- 场景采用印象派光色、梦幻感与超现实流体，保持路线、部署点与战斗信息清晰。
- 来袭者采用丑陋怪异的浊墨生物，通过不对称、硬壳、黏液和旧布形成辨识度，不照搬已有怪物。
- 最新需求扩展为十张不同场景关卡，以清完波次而非计时判定通关，支持一倍/两倍速。怪物必须严格沿河道移动。
- 第一版建议八名基础守卫加四名特色招募守卫、一至五星分布、八类怪物与五种道具。初始只解锁一名一星角色，基础角色逐步开放。
- 局内金币用于部署和当局升级，通关星尘用于永久培养和道具；增加角色与怪物图鉴。
- 招募更新为整卡、专属碎片、道具和星尘混合奖池，用游戏内星愿邮票或星尘，不接入真实支付。核心角色仍固定解锁，特色五星有明确的心愿碎片里程碑。
- 补充可跳过开场动画、主菜单、顺序解锁选关、商店道具造型与说明、升级前后数值对比，以及十关奖励预算；详见 `docs/dream-guardians-ui-and-economy.md`。当前仍是方案阶段，未替换可玩页面。
- 名称、美术、地图、界面、音乐和角色设定需要独立设计。
- 独立项目目录、独立游玩入口、独立作品档案。

## 网站组织约定

每个新游戏放入 `games/<game-id>/`，包含自己的页面、逻辑、样式和资源。贪吃蛇保持独立。前面的开灯区域提供小游戏切换入口，后面的电脑文件夹归入小游戏分类，每个游戏作为单独作品显示。

此文件是开发记录，不创建自动任务，不自动发布网站。

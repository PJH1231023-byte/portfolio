# 浮光守卫：十关小游戏策划案

更新日期：2026-09-07。当前为玩法与内容设计，不代表已实现的可玩版本。

## 已确认方向与策划建议

用户认可横向河道塔防与印象派梦幻画风，明确要求：怪物严格留在蓝色河道内、保护有生命值的莲花、以清完怪物而不是计时判定过关、支持一倍/两倍速、不同怪物属性、十个不同场景、初始只解锁一名一星角色、逐步解锁与升级、角色/怪物图鉴，以及可考虑的抽卡与道具商店。

最新建议范围：十张关卡、八名基础守卫加四名特色招募守卫、八类怪物（含一名首领）、五种道具，以及整卡/碎片/道具/星尘混合招募池。名称、奖励、概率和数值属于待试玩校准的设计提案，不能把概念图中的星星和费用当作最终配置。最新页面、开场动画、培养数值和经济规则见 `docs/dream-guardians-ui-and-economy.md`。

## 定位

以《保卫萝卜》式固定路线、岸边布防和终点生命为战斗基础，加入轻量的角色招募、收藏和养成。借鉴《明日方舟》的角色分工与队伍搭配，不引入庞大的基地、材料树、装备、体力或付费系统，也不复制其近战阻挡结构。角色、地图、界面、设定、素材与具体数值独立设计。

核心循环：选关和准备队伍 -> 布置守卫 -> 击败波次获得局内金币 -> 建造与升级 -> 莲花存活通关 -> 获得永久奖励 -> 培养/招募/购买道具 -> 进入新场景。

## 一、战斗硬规则

### 怪物路径

- 河道轮廓、中心路径和禁止部署区域由同一套关卡路线数据驱动，不能让背景美术与移动轨迹各自独立。
- 每个怪物持有 routeId 与沿路线的行进距离，位置从连续路径采样得到，不自由寻路到草地。
- 弯道沿真实曲线或路径段移动，不能直接朝终点追踪、切过河岸内角。
- 同种怪物的基础移动速度固定；不同怪物可以不同。减速、冻结等改变的是沿路线的速度，不改变路线。
- 路宽、转弯和贴图锚点必须容纳怪物完整视觉轮廓，包括最大的首领；横向摆动不能越过安全边界。
- 多入口各有自己的路径，可合流到同一莲花，不能在入口之间随机跳线。
- 分裂和召唤产生的小怪继承对应路线及进度，生成在河道内。
- 不用怪物之间的实体挤压把它们推出河道；通过进场间距和受限的视觉错位表达队列。
- 守卫只部署在合法岸边点，不堵河道，也不成为普通怪物的近战目标。

### 胜负与波次

- 不采用倒计时生存，也不把通关用时作为过关门槛。
- 胜利条件：全部预定波次已生成、场上怪物及其分裂/召唤后代都已解决、莲花生命大于零。
- 每个怪物拥有独立生命、护甲、基础速度、奖励和漏怪伤害。
- 怪物抵达终点只结算一次漏怪伤害，然后退出；不会反复扣血。
- 莲花生命归零立即失败，不允许失败后用道具复活。
- 失败重玩当前关；已解锁关卡、角色、永久培养与历史成绩保留。
- 每个新关卡使用新的地图布局和波次配置，局内金币与守卫部署重置，莲花恢复该关初始生命。

### 控制

- 支持一倍/两倍速和暂停。
- 两倍速同时作用于怪物位移、守卫攻速、出怪间隔、技能持续时间和道具冷却，不能只加快怪物。
- 顶部显示莲花生命、局内金币、当前/总波次、暂停与倍速，不显示关卡倒计时。
- 点击放置点选择守卫；选中已部署守卫查看射程、升级、出售或设置优先目标。
- 可指定攻击障碍物，清理后开放新落脚点并获得局内奖励。

## 二、角色与星级

第一版建议八名角色，覆盖一至五星，不再出现概念图里几乎相同的三星占位。

| 角色暂名 | 星级 | 定位 | 固定获得节点 |
| --- | --- | --- | --- |
| 萤巡 | 一星 | 快速单体光弹，基础输出与补漏 | 初始唯一解锁角色 |
| 苔豆 | 一星 | 射速较慢、单发较重的种子弹 | 首通第1关 |
| 露米 | 二星 | 水泡减速，延长火力窗口 | 首通第2关 |
| 烬团 | 二星 | 近程火焰、持续灼烧 | 首通第3关 |
| 绵汐 | 三星 | 花形范围攻击，清理怪群 | 首通第4关 |
| 回音 | 三星 | 音波削弱护甲，搭配单体输出 | 首通第5关 |
| 泊泊 | 四星 | 提灯增益，提高附近守卫效率 | 首通第6关 |
| 弥洛 | 五星 | 画笔光束，长射程穿透与高输出上限 | 首通第8关 |

获得节点是建议，不是已验证的平衡结果。这八名为基础进度伙伴，不加入最新特色招募池；另有四名四至五星伙伴通过招募或专属碎片获得，详见界面与经济补充方案。

第一关只有萤巡一种角色类型，但允许在不同位置部署同类型守卫，避免单塔无法形成基本布防。后续每关最多携带四种已拥有角色，同类型可部署多个；部署费用、点位和局内经济限制数量。

### 三种概念分别显示

- 稀有度：一至五星，角色固定身份，不因局内升级变星数。
- 永久培养：建议 Lv.1 至 Lv.5，用通关星尘提升并跨关保留，增幅适度，不要求刷满才可过关。
- 局内强化：建议 I、II、III 阶，用这一局的金币购买，新关卡重新布置。

高星同定位角色有更高上限和更明显技能优势，但部署更贵；低星保留低费用、前期启动和补漏价值。减速与增益不能仅按伤害排行。

永久培养可以在 Lv.3 增加标志性配饰，在 Lv.5 强化服装细节和技能表现，不依靠单纯放大贴图。各角色配置攻击、攻击间隔、射程、目标数、特殊效果与费用，不能只是星级不同、技能相同。

## 三、资源与奖励

| 资源 | 获得方式 | 用途 | 是否跨关保留 |
| --- | --- | --- | --- |
| 战斗金币 | 开局资源、击败怪物、清理障碍 | 部署、局内强化、布局调整 | 否 |
| 星尘 | 首次通关、重复通关的小额奖励、图鉴目标 | 永久培养、道具商店与星愿招募 | 是 |
| 星愿邮票（招募券） | 首通奖励和有限图鉴里程碑 | 一次星愿招募 | 是，作为道具保存 |

招募券不是第三套可充值钱包。不加入真实支付、体力、付费复活或限时逼迫领取的奖励。

首通奖励与重复通关奖励分开，首通只领取一次；重复通关仍提供少量星尘，让玩家可以补充培养或道具。基础奖励按过关给，不要求零漏怪。历史关卡可重玩。

击败怪物的金币、图鉴击败数和分裂处理都只结算一次；漏到终点的不记作击败。奖励结算需要幂等记录，刷新或重复点击结算不能重复领取首通奖励。

## 四、星愿混合招募

- 第3关后开放，消耗一枚星愿邮票或100游戏内星尘，不接入真实充值。
- 池中增加四名特色伙伴，不抽基础八名进度伙伴；可以获得整名角色、专属碎片、道具和星尘。
- 普通概率暂拟：四星整卡3%、五星整卡1%、四星碎片25%、五星心愿碎片15%、道具36%、星尘20%。
- 四星12片、五星24片可邀请对应伙伴；每5次招募额外给6片当前心愿五星碎片，同一心愿20次里程碑可确定收集24片。
- 重复整卡和已拥有角色的碎片按公示规则折算星尘，不追加突破系统。每项实际奖励、概率、消耗和里程碑在界面明确展示。
- 十关奖励预算、特色角色、概率细分与折算规则统一见 `docs/dream-guardians-ui-and-economy.md`；此前纯角色池和连续重复保底方案已被此方案替代。

## 五、怪物图鉴

建议八类：基础墨团、针足快行怪、裂壳泥兽、孢囊分裂怪、裹布再生怪、噬光护盾怪、唤墨者、浊墨首领。

- 首次遭遇记录轮廓与名称；首次击败解锁正式图像、简介、血量档位、速度、护甲、技能和推荐应对。
- 记录历史击败数量；分裂生成的小怪按其真实类别记录。
- 未见过的敌人保留剪影，新的关卡在开战前预告主要威胁，不要求玩家盲猜。
- 怪异感来自浊墨、黏液、大小眼、不规则肢体、硬壳与绷带，保持童话绘画质感，不依靠写实伤口。
- 单位血量、移动速度和攻击方伤害须可读；被减速、护盾、护甲和再生有不同视觉标识。

怪物简介采用性格化短句，例如：裂壳泥兽把干掉的旧颜料背在身上，走得慢，却很难打穿。攻略信息另列，不让故事文案替代功能说明。

## 六、道具商店

第2关后开放，用星尘购买。第一版做五种，详细图标、价格与数值见界面与经济补充方案：

| 道具 | 功能 | 限制 |
| --- | --- | --- |
| 晨露瓶 | 恢复莲花少量生命 | 不超上限，失败后不能使用 |
| 止水沙漏 | 短时间全场减速 | 首领效果减弱，不改变任何怪物路线 |
| 星火瓶 | 对选定河段造成范围伤害 | 不能直接秒杀首领 |
| 花幕护符 | 抵挡下一次漏怪伤害 | 不叠加，使用后有清楚的护盾标记 |
| 晨辉合剂 | 短时间提高已部署守卫攻击力 | 不叠加同类增伤，与战斗倍速同步 |

每关最多携带两件消耗品，预选不扣库存，实际有效使用才扣。商店预览清楚写出效果、价格和库存；不能对无效目标扣道具。基础阵容和合理部署应能不用道具通关，道具是容错而非门票。

## 七、十张关卡草案

每张地图都变化路线或战术结构，不仅换背景颜色。新增敌人逐步混入既有敌群，不必每关重新制作完整怪物阵容。

| 关卡 | 场景与配色 | 路线/场地 | 教学与挑战 |
| --- | --- | --- | --- |
| 01 晨露花庭 | 浅绿、奶油黄、淡蓝 | 简单单入口L形 | 一星开局，部署、升级与漏怪生命 |
| 02 杏霞浅湾 | 杏粉、暖白、湖蓝 | U形弯道 | 引入快速怪，学习弯道覆盖 |
| 03 青瓷水苑 | 青瓷绿、银白 | 横向S形 | 引入护甲怪，比较单体与持续伤害 |
| 04 雾苔回廊 | 苔绿、灰蓝、雾白 | 双入口汇流 | 两路分配资源，而不是所有火力堆一边 |
| 05 玻璃花房 | 透明青、浅桃、珠白 | Z形与可清理结晶 | 分裂怪与清障开放关键位置 |
| 06 琥珀浮岸 | 蜂蜜金、赤陶、浅蓝 | 长短两条路合流 | 再生怪与集中火力、增益站位 |
| 07 荧夜水庭 | 靛蓝、萤绿、月白 | 蛇形多弯 | 护盾怪和混合队列；夜色不降低可读性 |
| 08 蔷薇逆流 | 玫瑰、奶油白、湖蓝 | 三入口先后激活 | 唤墨者和分裂后代，区分入口时序 |
| 09 银雨镜湖 | 银灰、冰蓝、浅金 | 有限落脚点、汇流瓶颈 | 护甲、快行与分裂组合，选队和费用取舍 |
| 10 晨曦花冠 | 晨光金、天蓝、珊瑚 | 双入口、多段折返 | 首领与混合波次，综合使用已有机制 |

道路更长不自动更难，因为火力覆盖时间可能增加。难度通过入口时序、怪物组合、放置点与经济共同调校。每关清理完所有波次才结算；场景的雾、雨和流体装饰只在视觉外围，不遮蔽路线与单位。

## 八、页面与保存结构

主界面包含：可跳过的短开场、开始/继续按钮、十关地图、守卫图鉴、浊墨图鉴、星愿招募和道具商店。十关地图按顺序解锁，已通关可重玩。

角色图鉴展示已拥有/未拥有、稀有度、永久等级、技能、费用、射程与培养入口。怪物图鉴展示发现和击败记录。未开放功能在早期通过简短提示解释解锁条件。

本地保存：已解锁关卡与角色、角色培养、历史通关成绩、首通领取状态、星尘、招募券与保底计数、道具库存、怪物发现和击败记录、音效偏好。保持纯本地小游戏，不承诺跨设备云同步。

## 九、实现顺序与边界

1. 先完成第一关的严格路径、守卫放置、伤害、金币、升级、胜负和一/二倍速。
2. 再完成地图、角色和敌人配置结构，扩展十关与八名角色。
3. 接入固定解锁、永久培养、奖励、图鉴、轻量商店与免费招募。
4. 以实际可玩布局制作背景和角色素材，保证道路数据与画面吻合，再接回作品集独立入口。

本轮只更新策划文档，不把概念图宣称为可玩游戏，不替换已有塔防原型，也不改动贪吃蛇或绒绒野餐会。

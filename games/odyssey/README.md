# 奥德赛 · 英雄之旅

四张原作竖屏界面依次承担启航、战斗、胜利和奖励。战斗页面按当前窗口高度完整适配，不出现悬浮说明面板。图鉴入口在顶部菜单左侧，教学与图鉴仅主动打开。

直接点击卡牌出招；行动力为零、手牌为空或所有手牌费用不足时，750ms 后自动结算敌方攻击、补满行动力并抽牌。敌人动作与伤害通过场内短提示显示，不弹出确认窗口。菜单或切换标签页会暂停待处理攻击，关闭菜单后恢复，避免重复结算。存档中的零行动力也会自动恢复流程。

举盾等待将每点剩余行动力变为 2 点护盾，随后自动迎接敌人攻击。键盘 1–3 出牌、E 举盾等待、Esc 菜单。三关以生命归零判断胜负，画面中央显示关卡进度而非回合计数。战后永久祝福与生命修复影响后续关卡。

原作图片没有修改，动态手牌引用原作卡牌插画。所有游戏状态保存在浏览器本地，无第三方服务。

验证：node scripts/check-odyssey.cjs 与 node scripts/check-odyssey-ui.cjs。

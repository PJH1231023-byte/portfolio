# 精灵漫游

原创珠宝幻想横版游戏。原生 JavaScript + Canvas，无构建步骤，无外部运行时依赖。静态 HTTP 服务打开 index.html；固定 1280×720 横屏视野，支持键盘和手机横屏触控。

## 新版六关

五位主角为 03 慢拍、04 棱棱、09 贝眠、10 星啾、12 晶甲；保持确认造型，晶甲使用明亮配色。04、12 原图朝左，渲染按原图朝向与移动方向共同计算翻转。

六关全部开放，没有难度选择或锁关，每关独立记录时间与 1–3 星。

| 关卡 | 路线与机关 | 三星 / 两星目标 |
| --- | --- | --- |
| 粉晶花园 | 连续花阶、长廊、弹簧花 | 95 / 155 秒 |
| 珍珠水廊 | 贝壳拱桥、长短水廊、升降台 | 110 / 175 秒 |
| 翡翠瀑谷 | 瀑布、多层栈道、上升气流 | 115 / 180 秒 |
| 紫晶洞窟 | 洞内晶柱、碎裂后恢复的晶桥 | 115 / 185 秒 |
| 琥珀潮岸 | 礁石、潮池、有预警的潮汐喷泉 | 120 / 195 秒 |
| 月光浮岛 | 月石台座、星链、中段必须搭乘的宽渡台 | 135 / 210 秒 |

暂停与结算窗口可直接更换关卡，取消选关会回到原窗口。HUD 显示路线百分比；指南增加各关机关说明。水球、散射晶刺与贴地冲击波使用不同形状；碎桥在踩前可看见裂纹，恢复后可再次碎裂。

3.2 版为每关上层路线加入三枚旅途印记，共 18 枚。六种图形分别为粉晶花印、珍珠贝印、翡翠叶印、紫晶棱印、琥珀潮印、月光星印；短路牌指向所在高台，完整提示在本关指南。印记独立于时间星级，收到即保存在当前浏览器，失败、退出和刷新后保留，重玩可补齐。地图显示累计收藏，HUD 显示本次收集，庭院旅人手册展示六组收藏。

关卡宽度约 1.9–2.2 万世界单位，有主路线、上层岔路、补给和灯塔。熟练自动路线约 66–81 秒；首次玩家时长尚未做用户实测。上层机关用于探索与收集，无须清空全部怪物。终点是发光拱门，末段上层有返回地面的路牌。

## 战斗与操作

- 方向键 / A、D 移动；空格 / W / 上键二段跳；下键 / S 下穿薄平台；按住 J / X 或触屏攻击键连续攻击；H / 右上问号查看说明；P / Esc 暂停。
- 用尽二段跳后，落地前 120 毫秒内的跳跃输入会在落地时执行一次；过期输入自动清除。暂停、指南与重新开始会清空未完成的输入。同方向按键和多个触点独立记录，松开一个不会清除另一个；长按暂停键不会反复切换暂停状态。
- HUD 随时间显示三星剩余时间、两星剩余时间或一星通关提示，触屏攻击键的外圈显示攻击冷却恢复。
- 开始前默认显示完整说明，确认后才计时；可勾选不再自动提示，也可在设置中重新开启。游玩和暂停菜单内都能查看，查看期间暂停计时。
- 05 小猪：冲撞，基础伤害 8，可踩倒；07 水鸟：瞄准水球，伤害 12，可踩倒。
- 06 晶刺兽：三发散射晶刺，伤害 20，不可踩；08 巨兽：冲击波，伤害 26，不可踩。
- 11 玉蟹：近身钳击，伤害 16；晶光被甲壳抵挡，需要从上方踩踏破甲。
- 精英怪血量与接触伤害更高。敌人分布在地面和高处平台，各自巡逻，不跳跃；攻击前有蓄力感叹号。
- 怪物死亡后消失、失去碰撞与攻击能力，残留弹体一起消散。晶光有发射弧光、拖尾、命中碎光，踩踏也有反馈。
- 100 血量；粉色药水恢复 35，蓝色护盾保护 6 秒；跌落扣 20 并回到已点亮灯塔。通关显示祝贺、用时、星级、收集数与击败数。

## 大厅与存档

实际素材加载进度、五角色入场、点选伙伴、鼠标星光、公告、声音、设置、本地旅人资料。钟琴背景旋律在用户手势后启动；可分别设置音乐、音效和音量。设置包含减少动态、装饰粒子、指南和全屏。

3.2.1 修复庭院入场重影：直接动画展示区的五个角色元素，按选角栏顺序错开入场，随后接入待机浮动；取消原来的五张动画副本。入场期间侧边角色不接收误点击，底部选角仍可使用，选角或开始游戏会结束开场并清理计时器。系统与游戏内的减少动态偏好均受支持。

3.3 将展示区改成五个角色画布，并为原有透明纹理增加二维部位动画。慢拍摆动披风与小脚，棱棱保留抱臂姿态、点头与摇动晶石尾巴，贝眠挥手，星啾拍翅与小跳，晶甲交替迈动脚爪。游戏中的步态相位按实际移动距离推进，起跳、下落和攻击有各自姿态，移动中的攻击保留脚步动作。

3.3.1 按最新反馈将伙伴互动短片移至作品集。游戏主页改回约 1.26 秒的快速纵深入场：五位精灵按 03、04、09、10、12 顺序，每位间隔 110 毫秒，由远处缩小、淡入并飘近。使用同一组五个画布，无静态副本、走路小剧场、对白或重播按钮。选角和开始游戏可以立即中断入场；离开庭院停止动画，减少动态时直接显示原始造型。游戏中的行走、转身、起跳和攻击部位动作继续保留。

存档键仍为 portfolio.spirit-roam.v1，内部 schema 为 version 3。旧短关成绩归档，可在旅人资料中查看；新版路线重新记分，保留选角和声音偏好。月光浮岛中段在 3.1 版新增必经渡台，其旧路线成绩也单独归档，其他五关成绩不受影响。不提供联网账户或云存档。手机竖拿显示横屏提示；转竖屏、切后台或失焦暂停，旋回横屏后手动继续。

- game.js / audio.js：渲染、输入、界面状态与背景音乐。

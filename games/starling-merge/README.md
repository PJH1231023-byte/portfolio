# 绒绒野餐会 / Little Picnic Club

独立的弹珠三合一游戏。通过静态 HTTP 服务打开 `index.html`，无构建步骤、无第三方运行时依赖。鼠标、触屏与键盘共用同一套玩法。

## 主题与旅程

- 打开游戏先显示独立封面与主菜单，不直接进入发射状态。封面可选择主题，显示已保存关卡，并提供开始／继续、玩法、图鉴和设置。
- 游戏内的“菜单”暂停当前桌面，可查看说明、调整音效、更换头像，或保存后返回主菜单。重开整局须经过确认，取消不会重置存档。
- 从封面打开帮助或图鉴后关闭，仍停在封面；只浏览封面不会自动覆盖另一标签页正在进行的存档。
- 嵌入作品集时隐藏外围介绍侧栏，使完整的游戏桌面适应窗口高度。

- 绒绒动物园和点心野餐会从一开始就可以自由选择；每个主题各有八关，顺序解锁。
- 八个关卡是一整局的连续阶段，不是八个重新布置的独立桌面。过关保留桌面、发射队列、星光、累计发射次数和剩余撤回次数。
- 每关合成指定数量与等级的伙伴，没有强制发射次数上限；桌面触及安全线且尚未完成目标时失败。完成目标的同一次结算触及桌边时，优先判定过关。
- 关卡目标依次是：一个二级、两个三级、一个四级、两个四级、一个五级、一个六级、一个七级、一个八级伙伴。
- 每关根据使用的发射次数获得一至三颗星，重玩保留更好的成绩；两组旅程共可收集 48 颗星。
- 两套主题分别保存关卡、星星与当前桌面。切换主题不清空另一套旅程。
- 失败可以消耗剩余撤回次数挽救，或者从第一关重开整局；不能直接重玩当前关或跳到历史关卡。历史最佳星星与最高星光保留。
- 发射池不再追随当前关卡，也不再优先补齐桌上的对子。第三级被发现前，第一、第二级随机权重为 60:30；发现第三级后固定为 60:30:10。第四级及以上只能合成。
- 最低级始终可能出现，即使桌上已经没有该等级的伙伴；合成高级伙伴不会把低等级从池中移除。
- 玩家头像独立选择，可用八只新动物或八个经典角色；更换头像不更换游戏主题。
- 原版星灵不再作为发射物出现，仅保留在经典头像分组。

## 操作与规则

- 在桌面按住瞄准，松手发射；左右方向键瞄准，空格或 Enter 发射。
- 三个同级且相邻成组的伙伴合成下一等级，多余的同级伙伴保留。合成距离独立于物理碰撞，按体积提供约 18 至 26 个游戏单位的额外容差，不要求严丝合缝接触。最高等级不再继续升级。
- 合成获得星光，连锁有额外奖励。
- 每四次发射，桌面伙伴向下移动；结算时触及安全线则失败，已完成本关目标除外。
- 每局三次撤回，不随过关补满；每次发射前可以交换当前与下一位伙伴一次。进入下一关后不能撤回上一关的通关发射。
- P 暂停，Esc 暂停并通知主站返回展台。关闭灯光或离开标签页会暂停。
- 发射过程中离开时保留发射前快照，避免载入未结算的局面。

## 文件

- `index.html`：野餐界面、主题入口、任务卡、头像与图鉴弹窗。
- `style.css`：鼠尾草绿与奶油色的响应式界面，桌面侧栏和移动端单列游戏。
- `engine.js`：确定性圆形碰撞、三合一和桌面结算。碰撞使用圆形模型，但角色没有可见圆圈。
- `campaign.js`：八关配置、开场布局、过关判定与星级计算。
- `series.js`：两组角色名称、颜色与图集地址。
- `texture.js`：图集抠像、主体分离与透明显示纹理生成。
- `game.js`：绘制、操作、主题旅程、头像、存档、音效和主站通信。
- `ART-DIRECTION.md`：美术决策、参考来源与生成提示词。

## 保存与接入

新版存档使用 `portfolio.starling-merge.picnic.v2`，包含两套旅程、选择的主题、头像、音效偏好和最高星光。连续闯关的每局快照带有 `ruleVersion: 3` 和本关起始发射次数。旧版存档键不删除，载入时尝试迁移兼容的局面，并把旧规则的高级发射队列替换为低级随机队列；不会直接清空旧桌面。需要体验完整新节奏时，可从暂停菜单确认重开整局。存档仅在当前浏览器与站点来源内有效，不是云端账户。

主站通过 `js/data/works.js` 的 `starling-merge` 条目接入；开灯区域的游戏切换器与电脑的小游戏分类继续指向同一个独立项目。主站封面位于 `images/little-picnic-club-title.png`，详情另展示动物与点心两个主题的实机界面。

本次不改变贪吃蛇，也不扩展后续萌宠塔防。后续计划见 `docs/game-roadmap.md`。

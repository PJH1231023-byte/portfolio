# 葫芦数字博物馆 · 策展流程演示

当前作品集入口：`http://localhost:4187/apps/gourd-museum/demo.html`。这是一段 32 秒自动播放的网页演示，支持暂停、重播和按章节查看。原项目的工作方式由用户补充：光线充足时用手机拍摄真实葫芦，上传 MVP 自动抠图，作为伪 3D 图片展品放到书架、桌柜和地面，还可一键打乱所有上架藏品、切换家具皮肤。

`demo.html`、`demo.css`、`demo.js` 编排五个步骤；`tour-scene.js` 在已有展厅中用透明图片平面演示伪 3D 陈列与重排。照片与抠图为明确标注的示意素材，页面没有上传或抠图服务。保留 `index.html` 的早期交互样例作为场景基础；作品集统一指向新的流程演示，不新增重复作品。

`node scripts/check-gourd-film.cjs` 检查演示章节、播放暂停、场景加载、About 与项目入口，以及窄屏布局。About 保留原图片与简介，不插入视频。

## 早期交互样例

这是作品集里的小型交互样例，根据用户提供的原项目照片和演示视频重新制作。原项目是与葫芦手艺人的协作实践，参与内容包括数字展示空间、作品上架和家具皮肤设计。本目录提供陈列与换肤体验，使用六种程序化示例造型，不代表原项目的全部功能或真实藏品资料。

入口：`http://localhost:4187/apps/gourd-museum/`。作品集的“产品与交互”文件夹、项目详情和 About 卡片均可进入。

## 可体验的内容

- 三组木质展柜，每组四层，合计 36 个展位，初始陈列 24 件示例葫芦。
- 胡桃木、浅竹木、墨色描金三种家具皮肤，同步应用于展柜、边桌和矮凳；三种墙面颜色。
- 拖动旋转视角、滚轮缩放、点击三维葫芦选中展位；也可用视角按钮和展位按钮操作。聚焦画面后，左右方向键转动，`+` / `-` 缩放。
- 选择展位后点击藏品替换，也可以移回藏品库。支持最近 25 次撤销和恢复示例。
- 点击“保存展厅”写入当前浏览器的本地存储，刷新后恢复。该存档不会上传或跨设备同步。
- 窄屏将布展面板放到展厅下面；无 WebGL 时显示原项目照片。

## 实现与检查

`model.js` 管理藏品、皮肤和存档校验；`museum.js` 用仓库内的 Three.js 与 OrbitControls 绘制三维场景和处理交互；无需网络服务或新依赖。页面只在操作、视角变化和尺寸变化时重绘。

在仓库根目录运行 `node scripts/check-gourd-museum.cjs`，通过 Chrome 检查上架、移除、撤销、保存刷新、皮肤、视角、三维点选，以及 About 和作品文件夹的入口。检查截图输出到 `output/gourd-check/`。

原始照片保留在 `images/gourd-museum-display.jpg`。原演示视频留作素材参考，不在 About 或本项目详情中播放。

# 宠物健康记录 · 手机交互演示

这个目录包含完整的静态应用，页面、脚本、样式和四张原始设计稿都在目录内。无需构建或安装依赖，可作为作品集的一部分，也可以把本目录单独发布到静态网站空间。入口为 `index.html`。

顶部“作品集”链接用于返回本作品集；独立发布时可按需要修改该链接。应用运行不依赖作品集脚本或其他游戏。

## 页面与原稿

- 首页沿用原稿的完整插画与布局，用真实按钮和动态文字接通交互。
- 新增记录沿用第二张原稿的猫狗插画、三种记录类型、喂食表单、活动与健康栏、照片区和保存按钮。
- 宠物档案沿用第三张原稿的插画与卡片位置，内容改为中文并显示当前宠物的资料。
- 顶部“设计说明”打开第四张原始配色与组件设计稿。

## 交互流程

1. 初始示例日期为 2024年5月20日，与首页原稿对应。点击“今日日期”可选择其他日期。摘要只计算所选日期、当前宠物的记录。
2. 点击咪咪或旺旺切换宠物。点击“查看档案”，再点击铅笔或信息卡片，可修改昵称、年龄、身高、体重、生日、喂食目标和偏好。保存后名字同步到各页。
3. 点击“今日摘要”中的喂食、遛弯或健康状态，会编辑当天最近的一条对应记录；当天没有对应记录时进入新增。编辑保留记录编号，不会增加次数。
4. 点击“快速操作 → 新增记录”，选择类型并填写。底部提示当前将保存的类型；每次保存一条所选类型的记录。表单中的其他类型可点击切换。
5. 每个记录栏右侧的“编辑”按钮可以补充日期、时间和备注，编辑已有记录时也能删除该记录。底部“保存”后才写入档案并回到首页。
6. 点击照片区上传实际照片。支持 PNG、JPEG、WebP、GIF、AVIF，每张不超过 1.5 MB。图片随记录保存，之后可以替换、移除，也可以在“已保存的记录”里查看。
7. 健康页显示填写的健康观察、疫苗与记录列表，不生成医学诊断或虚构评分。异常症状与“正常”互斥，异常记录不会显示为良好。

数据仅保存于当前浏览器本机，不会上传到服务器，也不会跨设备同步。浏览器存储失败会明确提示；“重置”经确认后会清除本机演示数据并恢复示例。
